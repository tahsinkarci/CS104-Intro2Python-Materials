Pick which of the five Python files to animate. The small line under each name says which method it uses. The dark tab is the one on screen. If you switch while the animation is playing, the new file starts from the beginning.

2 · Control bar

There are three ways to move: play it continuously, jump one loop iteration at a time, or step one code line at a time.

Play / Pause

Runs the animation on its own, one code line after another. Press again to pause. At the end, Play starts over from the first step. This button also turns the sound on, because browsers only allow sound after a click.

Space

Previous step / Next step

Move exactly one code line back or forward. Use these to explain a single line, such as one print call or one if check. Stepping forward plays that line's sound.

←→
◀ ii ▶

Previous iteration / Next iteration

Jump to the start of the previous or next loop iteration, so one press equals one row of the letter. If you're in the middle of an iteration, ◀ i first goes back to the start of that same iteration.

Shift+←Shift+→

Restart

Goes back to the first step of the current file and pauses there.

Progress bar and counter

  • Drag the round handle to go to any step. Dragging pauses the animation.
  • Each small tick mark on the bar is the start of one loop iteration, so there is one tick per row of the letter. The ◀ i and i ▶ buttons jump from tick to tick.
  • The counter shows the current i and the step number, for example i = 1 · 9 / 27.
size −5+

Size

The number typed into input(), from 3 to 9. Changing it rebuilds the letter, the graph and every step. Try 7 or 9 on letterK.py to see the middle joint separate.

speed 1× ▾

Speed

How fast Play moves: 0.5×, 1×, 2× or 4×. Steps that print a single space run quicker, so grid files don't drag.

Sound onSound off

Sound

Turns the sound effects on or off. The page remembers your choice in this browser. The sound table explains each sound.

next file show spaces

Next file / Show spaces

  • next file: when one file finishes, Play continues with the next tab, so all five run as one tour.
  • show spaces: draws each printed space as a dot in the output, so you can count them. Turn it off to see the plain letter.

4Code

The file's code with a few short comments. The yellow line is running now, and the box under it shows the calculation with real numbers. The numbers on the left are the real line numbers in the .py file, so some numbers are skipped.

5Graph

  • Gap graph (K files and letterN.py): x is the row i, y is the number of spaces. A point appears each time spaces are printed.
  • Grid graph (letterNv2.py, letterNv3.py): every cell (row i, column j) lights up as it is checked. Teal cells match a wall (j = 0 or j = n − 1), blue cells match the diagonal i = j, and pale cells match nothing and print a space. The yellow outline is the cell being checked now.
  • Dashed lines show where the formula goes. The yellow band is the current row, and the gray dashed line marks where a K switches from going down to going up.

7Variables and iterations

  • Variables: the current value of every variable. A value flashes when it changes, and — means it isn't set yet.
  • Iterations: one chip per loop round. The outlined chip is the current one. Finished chips turn red or blue and show their gap.

8How it works

The method behind the current file, the key comments from the code, review notes such as typos or logic to check, and the target shape drawn at the top of the file. This panel scrolls on its own if it's long.

Colors

ColorMeaning
RedDecreasing line: the gap shrinks by 1 each row
BlueIncreasing line: the gap grows by 1 each row, or the diagonal j = i
TealConstant: the side walls of the N, or a sum that never changes
YellowWhat's happening now: the running code line, the current row, the current grid cell

Sounds

Sound starts after your first click on Play or a step button.

You hearIt means
Two rising chimesThe program reads the input number
Soft clickA new loop iteration starts
Short rising or falling beepAn if check is True or False
Sharp key clickA * is printed
Quick taps, then a noteOne tap per printed space, then a note whose pitch matches the gap size. A K sounds lower and lower, then higher again.
BellThe row ends with a new line
Four-note chordThe file has finished
